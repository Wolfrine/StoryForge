# StoryForge

StoryForge is a data-driven storyworld visualization and experience engine.

Creator agents write structured world data. The engine turns that structure into scenes, discovery paths, visual metaphors and progressively revealed story information. It is not a hand-built encyclopedia and it does not use entity-specific pages.

## Current status — v0.3

The experience is now scene-first:

- guided entry into the world rather than a menu-first landing
- bright/living visual direction by default
- generic scene families for landscape, portrait, rupture, ritual, civilization, abstract concepts and distortion
- imagery occupies the dominant first impression
- text is progressively disclosed below the visual scene
- relationships become nearby threads and Atlas connections
- Atlas mode remains free exploration
- Studio mode exposes meaning/provenance without leaking it into reader mode
- world integrity validation runs before every deployment
- no entity-specific page components

The current imagery is generated by reusable SVG scene families. The media model can later replace or layer these with generated artwork, photography, video or 3D without changing content schemas.

## Architecture

```text
Creator agents
    ↓
Storyworld schema
    ↓
World graph / normalized content
    ↓
Scene resolver + semantic theme
    ↓
Experience grammar
    ↓
Guided entry / World / Atlas / Studio
```

See `docs/ENGINE_V0.md` and `AGENTS.md`.
